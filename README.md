# PEB Duplex/Triplex Calculator Demo

This repository contains a standalone HTML prototype for the improved Duplex/Triplex price calculator requested by Pebify. Open `duplex-triplex-calculator.html` in a browser to preview the refreshed design and UX interactions.

Key highlights:

- Redesigned card layout with a focus on clarity, contrast and hierarchy.
- Accessible slider + numeric field pairing with real-time feedback chip.
- Animated price transitions and contextual messaging for large surfaces.
- Refined promo note with keyboard-friendly tooltip and enhanced CTA.

Feel free to adapt the markup, styles or logic to integrate it inside your project.
